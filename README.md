# BlackBox — Widgets

Widget brandizzati (nero/rosso, font Hitmarker) pronti da incorporare in Notion via `/embed`.

- `clock.html` — orologio + data live (Como/Ticino)
- `countdown.html` — countdown a una data (`?to=2026-12-31T18:00&label=Lancio`)
- `kpi.html` — cruscotto: progresso anno, target MRR, progetti (numeri in cima al file)
- `payoff.html` — header con payoff rotante
- `index.html` — hub con anteprime e URL da copiare

## Uso in Notion
1. Apri `index.html` (GitHub Pages), copia l'URL del widget.
2. In Notion: `/embed` → incolla l'URL.
